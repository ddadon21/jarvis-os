# SOP-002 — Work Intake & Delegation

**Version:** 1.0  
**Owner:** JARVIS / Chief of Staff  
**Authority:** HJV Constitution v1.0

## Purpose
Turn requests, detected gaps, incidents, and opportunities into bounded work without creating uncontrolled missions.

## Procedure
1. State the objective in one sentence.
2. Classify the source: Dwight, approved objective, incident, scheduled check, or agent proposal.
3. Identify the definition of done and evidence required.
4. Assign one accountable Lead agent.
5. Add supporting agents only when a dependency requires them.
6. Apply governance:
   - inside approved mission + reversible => proceed under existing ceiling;
   - mission expansion, money, external commitment, permissions, high blast radius => ask Dwight;
   - hard-limit action => block.
7. Maximum three agent follow-up tasks from one task unless the Chief of Staff explicitly consolidates them.
8. Close the task only when evidence reaches the required truth state.
9. Unfinished work remains visible; do not replace it with a new objective to create the appearance of progress.

## Definition of done
One owner, one objective, one evidence standard, one explicit final state: DONE, BLOCKED, WAITING_APPROVAL, FAILED, or CANCELLED.
